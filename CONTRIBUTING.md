# Contributing

Suggestions are welcome, as issues or pull requests.

- **Every change is reviewed by the owner before it merges.** These files are installed as instructions for coding agents, so changes are read closely, and anything that widens what an agent may do (new tools, network access, credentials, deleting files) needs a clear reason.
- **Keep a change small and focused.** One skill, or one fix, per pull request, with a short note on what problem it solves.
- **Skill layout:** see "Adding a skill" in the README. A new skill also needs its entry in `setup/manifest.json` for each agent it supports.
- **No secrets, personal paths or machine names** in any file.
